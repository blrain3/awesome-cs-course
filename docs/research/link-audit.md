# Canonical Link Audit

Audit date: 2026-09-06 (Asia/Shanghai)

Scope: the 45 unique external URLs present in `README.md` after the CS61B and CS144 replacements.

Method: an HTTP `GET` was issued for each URL with a descriptive user agent, TLS verification enabled, a 10 second connect timeout, a 25 second read timeout, and server redirects followed. The HTTP result below records the final response status and the redirect chain where one was observed. Page-content evidence is taken from the returned HTML title and visible navigation or course text. No current URL returned a 4xx/5xx response or timed out in this run.

Flags:

- `redirect` means a server redirect or an HTML meta/JavaScript redirect was observed.
- `index` means the destination is an index/landing wrapper rather than the underlying course page.
- `archived` or `term-specific` records the dated offering represented by the page or snapshot.
- `restricted` and `non-substantive` are used when access or page content prevents the destination from serving the promised material.

## Remediation notes

- **CS61B:** The former URL `https://cs61b.org/` returned HTTP 200 but failed normal TLS certificate verification. An insecure diagnostic fetch returned a 1,704-byte generic placeholder whose script calls `/__r` and renders "No advertisers available"; `/__r` served a base64-encoded webindex URL. Public DNS identifies `ns1.mxmpark.com` and `ns2.mxmpark.com` as the authoritative nameservers and an Afternic verification TXT record. The destination was therefore flagged as parked/non-substantive and replaced with the substantive Fall 2026 Berkeley page at `https://fa26.datastructur.es/` (HTTP 200; course calendar, policies, homeworks, labs, projects, and resources).
- **CS144:** The former URL `https://cs144.stanford.edu/` returned a `307` to `http://web.stanford.edu/class/cs144/`, then a `301` to a 190-byte HTTP 200 page whose only content was a meta-refresh to `https://cs144.github.io/`. That target returned GitHub Pages HTTP 404 and the repository `https://github.com/cs144/cs144.github.io.git` was not found. The README now uses the Wayback snapshot `https://web.archive.org/web/20260506063931/https://cs144.github.io/`, which returned HTTP 200 with a substantive captured Fall 2025 CS144 page; this is explicitly labeled `Archived` and remains an archive wrapper rather than a live first-party page.

No current row was access-restricted. Pages that expose a Login link (for example ETH DDCA or Stanford CS149) still returned public course content during this audit; they were not classified as restricted.
